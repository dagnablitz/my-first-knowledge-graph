# My First Knowledge Graph

Interactive, playful Knowledge Graph mapping **15 iPhone Chrome Tab Groups**, **10 Cross-Cutting Concept Bridges**, and **161 unique saved URLs (170 tabs)**.

## Live Features
- **Dynamic Zoom-to-Fill**: Click any node (Tab Group, Concept Bridge, or Saved Link) to automatically gather its 1-hop neighbors and zoom to fill 100% of your current screen size.
- **100% Whole Picture View**: Click **100% Fill (Whole Picture)**, click empty canvas space, or press `Esc` to smoothly zoom back out to the full network.
- **3 Layout Modes**: Switch between **Constellation (Force Physics)**, **By Tab Group (15 Galaxies)**, and **By Concept (10 Ideas)**.
- **Pathfinder (`Trace Path`)**: Select any node and click **Trace Path** to highlight the shortest conceptual path to any other node.
- **Accessible Directory & Table (`<dialog closedby="any">`)**: Browse and filter all 170 saved links in a structured collapsible directory.
